Pouvez-vous revoir complètement l’architecture et la navigation du module **Équipe & Ressources Humaines** de Gameasu ?

## Problème constaté

La structure actuelle est confuse et comporte plusieurs niveaux qui se répètent.

Par exemple :

* dans la barre latérale bleue, l’utilisateur clique sur **Mon espace** ;
* dans la zone blanche, il voit encore une section appelée **Mon espace** ;
* cette section affiche ensuite d’autres éléments comme Vue d’ensemble, Indicateurs RH, Rapports RH et Simulateur de coût.

Cette répétition donne l’impression que la même rubrique existe à plusieurs endroits et rend la navigation difficile à comprendre.

Je veux éviter les doublons comme :

**Mon espace → Mon espace**

ou

**Équipe → Collaborateurs → Collaborateurs**

Chaque niveau doit avoir une fonction claire et différente.

---

# 1. Appliquer une architecture hiérarchique à trois niveaux

Le module Équipe doit suivre cette logique :

### Niveau 1 — Grandes catégories dans la barre bleue

La barre latérale bleue doit afficher uniquement les grandes familles fonctionnelles, en gras.

Exemples :

* Mon espace
* Pilotage RH
* Collaborateurs
* Recrutement
* Intégration
* Structure
* Temps & Présence
* Paie
* Formalités administratives

* Registre légal

Ces éléments représentent les grands domaines RH.

# 2. Corriger la logique de « Mon espace »

**Mon espace** doit être réservé au collaborateur connecté.

Il ne doit pas contenir les fonctions globales de pilotage RH comme :

* Vue d’ensemble RH ;
* Indicateurs RH ;
* Rapports RH ;
* Simulateur de coût.

Ces éléments doivent être regroupés dans une catégorie séparée :

**Pilotage RH**

ou

**Tableau de bord RH**

### Mon espace doit plutôt contenir

* Mon profil
* Mes documents
* Mes contrats
* Mes congés
* Mes présences
* Mes bulletins de paie
* Mes avances sur salaire
* Mes demandes
* Mes réclamations
* Mes formations
* Mes évaluations

La rubrique doit s’adapter aux droits et au rôle de l’utilisateur.

---

# 3. Supprimer les répétitions

Ne pas répéter le nom de la catégorie principale dans le panneau détaillé.

### Exemple incorrect

Barre bleue :

**Mon espace**

Panneau blanc :

**Mon espace**

### Exemple correct

Barre bleue :

**Mon espace**

Panneau blanc :

* Mon profil
* Mes documents
* Mes congés
* Mes bulletins
* Mes demandes

Autre exemple :

Barre bleue :

**Collaborateurs**

Panneau blanc :

* Liste des collaborateurs
* Organigramme
* Départements
* Postes

### Responsable Paie

### Super Administrateur

* accès à toute l’architecture et aux paramètres.

# 6. Comportement visuel attendu

La barre bleue doit rester réservée aux catégories principales.

Quand une catégorie est sélectionnée :

* elle doit être la seule affichée comme active ;
* ses rubriques apparaissent dans la zone blanche ;
* les autres catégories restent visibles mais non actives ;
* le panneau blanc ne doit pas répéter le titre inutilement ;
* le fil d’Ariane doit refléter la hiérarchie réelle.

### Exemple de fil d’Ariane

**Équipe & RH → Paie → Fiches de paie**

ou

**Équipe & RH → Temps & Présence → Congés**

---

# 7. Réduire la complexité

Merci de vérifier pour chaque élément :

* s’il est au bon niveau ;
* s’il ne fait pas doublon ;
* s’il est compréhensible ;
* s’il doit être un menu, une rubrique, un onglet ou une simple fonctionnalité ;
* s’il peut être intégré dans un workflow existant.

Éviter d’afficher trop de niveaux simultanément.

Une fonctionnalité ne doit pas apparaître à plusieurs endroits, sauf lorsqu’il s’agit volontairement d’un raccourci contextuel.

---

# 8. Audit global du module Équipe

Parcourir tout le module Équipe et identifier :

* les doublons ;
* les menus mal placés ;
* les catégories trop chargées ;
* les rubriques isolées ;
* les incohérences entre la barre bleue et la zone blanche ;
* les liens qui ouvrent la mauvaise page ;
* les états actifs incorrects ;
* les problèmes de défilement ;
* les incohérences entre desktop, tablette et mobile.

---

# Résultat attendu

Je veux une architecture RH très claire :

**Barre bleue = grandes catégories**
**Zone blanche = rubriques détaillées**
**Page ou troisième niveau = sous-détails**

Il ne doit plus y avoir de répétitions comme **Mon espace → Mon espace**.

Chaque catégorie doit présenter uniquement les rubriques qui lui appartiennent réellement.

### Objectif final

Transformer le module Équipe & RH en une expérience simple, structurée et intuitive, permettant d’appréhender tous les aspects RH de manière globale, puis d’accéder progressivement aux détails sans confusion ni duplication.
