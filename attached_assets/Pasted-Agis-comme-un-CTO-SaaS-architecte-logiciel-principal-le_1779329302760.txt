==================================================
EXIGENCES FONCTIONNELLES IMPORTANTES
==================================================

L’application doit intégrer ou préserver les logiques suivantes :

### 1. Multi-tenant / workspace / organization
- chaque entreprise = un workspace / tenant
- isolation des données par organization_id
- rôles, permissions, paramètres et abonnements gérés par tenant

### 2. Packages SaaS
Créer des plans du type :
- Starter
- Growth
- Professional
- Enterprise

La logique de pricing doit inclure :
- frais fixes d’installation / onboarding
- abonnement mensuel ou annuel
- prix selon nombre d’utilisateurs
- modules activés selon le package
- logique d’upgrade

### 3. Accès et permissions
- accès contrôlé par tenant + rôle + package + affectation
- les utilisateurs ne voient que ce qu’ils sont autorisés à voir
- admin et managers autorisés gèrent utilisateurs, départements, rôles, permissions, projets, fichiers, chats, etc.
- onboarding sécurisé
- invitation email
- mot de passe à changer à la première connexion
- contrôle d’accès aux projets, fichiers, chats et membres selon affectation

### 4. Messagerie / communications
Le module Communications doit être moderne et inclure ou préparer :
- chat interne
- chat projet / équipe / client
- notifications temps réel
- bouton WhatsApp dans la messagerie redirigeant vers le numéro WhatsApp du contact
- traduction automatique avec sélecteur direct de langue
- voice-to-text si disponible
- pièces jointes
- partage de localisation si déjà prévu
- expérience calling / notifications plus fluide et professionnelle

### 5. Comptabilité
Le module Comptabilité doit être moderne, inspiré de QuickBooks / Xero, mais aligné avec les réalités régionales.
Prévoir :
- plan comptable
- journaux
- écritures
- grand livre
- balance
- factures
- paiements
- clients / fournisseurs
- trésorerie
- reporting financier
- lien fort avec commercial, services, projets, paiements, locations, etc.

### 6. Planification financière
Le module Planification financière doit permettre :
- budget entreprise
- budget par projet / service / département
- actual vs budget
- variance analysis
- forecast / prévisions
- export Excel des rapports

### 7. RH
Le module Équipe & RH doit permettre :
- collaborateurs
- équipes / départements
- postes / fonctions
- affectations
- documents RH
- rôle organisationnel
- synchronisation avec projets, tâches, opérations, matériel

### 8. Marketing
Le module Marketing doit permettre :
- campagnes email
- campagnes SMS
- ciblage clients / prospects / fournisseurs / collaborateurs
- alertes automatiques par email sur échéances, locations, paiements, retours, etc.

### 9. Gestion documentaire
Le module Documents doit permettre :
- organisation par client
- fournisseur
- projet
- service
- module
- location
- facture
- commande
- collaborateur
- recherche simple
- rattachement transversal aux entités métier
