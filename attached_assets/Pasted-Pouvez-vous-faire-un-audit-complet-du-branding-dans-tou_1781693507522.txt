Pouvez-vous faire un audit complet du branding dans toute l’application ? L’application s’appelle maintenant Gaméasù, donc je ne veux plus voir aucune mention de EDOLE, EDOLE Admin, ou tout autre ancien nom dans l’interface, les emails, les pages d’authentification ou les données système.

Comme on le voit dans le screenshot, la page d’activation affiche encore :

“Bienvenue dans EDOLE”

Cela doit être remplacé par :

“Bienvenue dans Gaméasù”

Objectif

Nettoyer complètement l’ancien branding EDOLE et s’assurer que toute la plateforme utilise uniquement le nom officiel :

Gaméasù

⸻

1. Remplacer toutes les anciennes mentions

Merci de rechercher et remplacer partout :

* EDOLE
* Edole
* edole
* EDOLE Admin
* Edole Admin
* edole admin
* edole.africa
* tout ancien nom ou ancienne référence liée à EDOLE

Par :

* Gaméasù
* Gaméasù Admin si nécessaire
* gameasu.com ou gameasu.tech selon le domaine actuellement configuré dans l’application

⸻

* page de création de mot de passe

* page d’onboarding tenant

* emails système
* titres de pages

* messages d’erreur
* sidebar

* kiosk
* notifications

* factures
* reçus
* rapports

⸻

3. Corriger la page visible dans le screenshot

Sur la page d’activation de compte, remplacer :

Bienvenue dans EDOLE

par :

Bienvenue dans Gaméasù

Et vérifier aussi :

* le titre de la page
* le texte d’introduction

* les métadonnées
* le nom affiché dans l’onglet du navigateur

⸻

4. Vérifier le code et les données

Merci de rechercher l’ancien branding dans :

* composants frontend
* fichiers de traduction
* constantes globales
* variables d’environnement
* fichiers de configuration
* templates emails

Aucune mention de EDOLE ne doit rester dans l’application.

⸻

5. Centraliser le branding

Pour éviter ce problème à l’avenir, merci de créer ou vérifier une configuration centralisée du branding, par exemple :

* appName = Gaméasù
* companyName = Gaméasù
* supportEmail = support@gameasu.com
* noreplyEmail = noreply@gameasu.com
* cockpitUrl = cockpit.gameasu.com
* mainDomain = gameasu.com

Toutes les pages doivent utiliser cette configuration au lieu d’avoir des noms écrits en dur dans le code.

⸻

6. Résultat attendu

Je veux que toute l’application soit cohérente avec le branding officiel Gaméasù.

À la fin, merci de confirmer :

* toutes les mentions EDOLE supprimées
* toutes les pages d’authentification mises à jour
* tous les emails système mis à jour
* tous les anciens emails / domaines remplacés
* tous les textes visibles corrigés
* les fichiers modifiés
* les endroits où l’ancien branding était encore présent

Objectif final

L’application doit être 100 % brandée Gaméasù, sans aucune trace visible de EDOLE ou EDOLE Admin, afin d’être prête pour une publication professionnelle.
