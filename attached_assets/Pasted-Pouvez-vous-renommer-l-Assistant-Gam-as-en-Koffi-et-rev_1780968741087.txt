Pouvez-vous renommer **l’Assistant Gaméasù** en **Koffi** et revoir entièrement sa logique afin qu’il devienne un véritable assistant intelligent capable de répondre à **toutes les questions liées à l’application** ?

### 1. Changement de nom
Merci de :
- remplacer partout **“Assistant Gaméasù”** par **“Koffi”**
- mettre à jour ce nom dans l’interface, les libellés, les titres, les raccourcis et toute autre référence visible

### 2. Retraining / amélioration de l’assistant
Je veux que **Koffi** soit beaucoup mieux entraîné pour pouvoir répondre à toutes les questions concernant :

- l’application dans son ensemble
- tous les modules
- toutes les sections
- toutes les sous-sections
- les workflows
- les fonctionnalités
- les actions possibles
- la logique entre les modules
- les parcours utilisateur
- les questions de support fonctionnel
- les questions d’utilisation courante

Autrement dit, je veux qu’il puisse aider l’utilisateur sur **tout l’écosystème de l’application**, et pas seulement sur quelques blocs limités.

### 3. Niveau attendu
Je veux que Koffi soit capable de :
- expliquer comment fonctionne un module
- guider l’utilisateur étape par étape
- répondre aux questions sur les fonctionnalités
- aider à naviguer dans l’application
- expliquer les liens entre les modules
- assister sur les opérations courantes
- offrir une aide plus complète, plus naturelle et plus utile

### 4. Changement d’emplacement / expérience utilisateur
Je ne veux plus que cet assistant reste dans le module **Pilotage** comme une simple sous-section.

Merci de :
- **retirer Koffi du module Pilotage**
- le transformer en une vraie expérience de **chat**
- le rendre accessible sous forme de **chat assistant** beaucoup plus naturel dans l’application

### 5. Résultat attendu
Je veux :
- un assistant renommé **Koffi**
- un assistant mieux entraîné et plus intelligent
- un assistant capable de répondre à toutes les questions sur l’application
- une expérience plus fluide sous forme de **chat**
- un assistant qui soit plus utile, plus visible et plus professionnel

### Objectif final
Je veux que **Koffi** devienne un véritable assistant applicatif central, capable d’accompagner les utilisateurs sur tous les modules, toutes les sections et tous les usages de la plateforme, dans une interface de chat plus naturelle et plus moderne.
