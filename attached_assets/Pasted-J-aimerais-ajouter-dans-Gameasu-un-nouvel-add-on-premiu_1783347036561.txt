Gameasu Assistant IA

1. Objectif de l’add-on

Créer un assistant IA intelligent, personnalisable et connecté à chaque tenant, qui peut agir comme une secrétaire virtuelle ou un agent d’accueil automatisé.

L’assistant doit pouvoir :

* répondre aux appels téléphoniques ;
* discuter avec les clients ;
* répondre aux questions fréquentes ;
* prendre des rendez-vous ;
* qualifier les demandes ;
* proposer des solutions ;
* orienter vers le bon service ;
* envoyer des notifications internes ;
* créer des tâches ou tickets ;
* enregistrer les interactions dans l’ERP ;
* transmettre les demandes importantes à un humain.

⸻

2. Assistant IA par organisation / tenant

Chaque organisation doit avoir son propre assistant IA, formé uniquement sur ses propres données.

L’assistant doit être capable d’utiliser les informations du tenant, par exemple :

* nom de l’organisation ;
* services proposés ;
* horaires d’ouverture ;
* coordonnées ;
* politiques internes ;
* FAQ ;
* tarifs ;
* équipes ;
* disponibilités ;
* procédures ;
* documents autorisés ;
* clients ;
* rendez-vous ;
* tickets support ;
* historique des échanges si autorisé.

Les données d’un tenant ne doivent jamais être mélangées avec celles d’un autre tenant.

⸻

3. Canal téléphone / voix IA

L’add-on doit inclure une fonctionnalité d’assistant vocal par téléphone.

Fonctionnalités attendues

* numéro dédié ou numéro connecté ;
* réception d’appels entrants ;
* réponse vocale automatique ;
* conversation naturelle avec le client ;
* prise de rendez-vous ;
* transfert à un humain si nécessaire ;
* transcription de l’appel ;
* résumé automatique ;
* enregistrement de l’interaction dans Gameasu ;
* création automatique d’une tâche, d’un ticket ou d’un lead si pertinent.

⸻

4. Personnalisation de l’assistant

Chaque organisation doit pouvoir personnaliser son assistant.

Paramètres à prévoir

* nom de l’assistant ;
* langue principale ;
* langues secondaires ;
* ton de communication ;
* genre de voix ;
* style de voix ;
* niveau de formalité ;
* message d’accueil ;
* message hors horaires ;
* règles de transfert vers un humain ;
* horaires de disponibilité ;
* services que l’assistant peut gérer ;
* informations auxquelles l’assistant a accès ;
* limites de réponse ;
* règles de confidentialité.

⸻

5. Langues et voix

L’assistant doit pouvoir gérer plusieurs langues selon les besoins du tenant.

Options souhaitées

* français ;
* anglais ;
* langues locales si disponibles plus tard ;
* possibilité de changer la langue de l’assistant ;
* possibilité de choisir une voix masculine ou féminine ;
* possibilité de choisir un style de voix professionnel, chaleureux, dynamique ou institutionnel ;
* possibilité future de cloner une voix avec consentement explicite et validation sécurisée.

Sécurité pour le clonage vocal

Le clonage vocal doit être encadré :

* consentement écrit obligatoire ;
* vérification de l’identité de la personne ;
* impossibilité d’utiliser une voix sans autorisation ;
* journalisation de l’activation ;
* possibilité de désactiver ou supprimer une voix clonée ;
* usage limité à l’organisation autorisée.

⸻

6. Cas d’usage principaux

L’assistant IA doit pouvoir gérer plusieurs scénarios.

Accueil client

* répondre aux questions générales ;
* présenter l’organisation ;
* expliquer les services ;
* donner les horaires ;
* orienter vers le bon service.

Prise de rendez-vous

* vérifier les disponibilités ;
* proposer des créneaux ;
* confirmer un rendez-vous ;
* envoyer une notification au client ;
* ajouter l’événement au calendrier ;
* prévenir l’équipe concernée.

Support client

* répondre aux questions fréquentes ;
* créer un ticket ;
* classer la demande par priorité ;
* assigner à un membre de l’équipe ;
* envoyer un résumé de l’échange.

Vente / prospection

* qualifier un prospect ;
* collecter les informations clés ;
* identifier le besoin ;
* proposer une solution ;
* créer un lead dans le CRM ;
* notifier l’équipe commerciale.

Ressources humaines

* répondre à des questions RH simples si autorisé ;
* orienter les candidats ;
* collecter les demandes de recrutement ;
* créer une tâche RH.

Permissions à prévoir

* activer l’add-on Assistant IA ;
* configurer l’assistant ;
* gérer la base de connaissance ;
* voir les conversations ;
* écouter les enregistrements ;
* voir les transcriptions ;
* supprimer une interaction ;
* connecter un numéro de téléphone ;
* gérer les voix ;
* autoriser la prise de rendez-vous ;
* autoriser la création de tickets ;
* autoriser la création de leads.

L’assistant ne doit jamais révéler :

* informations confidentielles ;
* données financières sensibles ;
* données RH sensibles ;
* informations personnelles non autorisées ;
* données d’un autre tenant.
