Can you please update the Gaméasù subscription model?

Objective

I want the subscription model to be simplified so that every tenant / organization gets full access to all modules.
There should no longer be packages that limit access by module.

The pricing should be based only on the number of users in the organization.

⸻

New subscription logic

Every tenant should have access to all Gaméasù modules, including:

* Finance
* Sales
* CRM
* HR
* Payroll
* Operations
* Stock
* Projects
* Reports
* Admin
* Cockpit
* All other active modules

The billing should be calculated based on the total number of users.

⸻

Pricing structure

All prices must be shown hors taxes / HT until the payment step.

User pricing

* 1st user: 10,000 FCFA HT
* Users 2 to 5: 5,000 FCFA HT per user
* Users 6 to 10: 2,000 FCFA HT per user
* Users 11 to 50: 1,000 FCFA HT per user
* More than 50 users: display Personalized pricing / Contact us

Example calculation

For an organization with 10 users:

* User 1 = 10,000 FCFA HT
* Users 2 to 5 = 4 × 5,000 = 20,000 FCFA HT
* Users 6 to 10 = 5 × 2,000 = 10,000 FCFA HT

Total HT = 40,000 FCFA

⸻

TVA logic

The subscription price must be displayed as HT before payment.

At checkout / payment step, apply 18% TVA automatically.

The payment summary should show:

* Subtotal HT
* TVA 18%
* Total TTC
* Number of users
* Billing period
* Payment method
* Amount due

Example

If the total subscription is 40,000 FCFA HT:

* HT: 40,000 FCFA
* TVA 18%: 7,200 FCFA
* TTC: 47,200 FCFA

⸻

More than 50 users

If an organization has more than 50 users:

* do not calculate automatically
* show: Tarification personnalisée
* show a button: Demander un devis
* allow the tenant to contact the Gaméasù team
* optionally create a quote request in the admin cockpit

⸻

Admin and billing updates

Please update the subscription, billing and tenant management logic so that:

* tenants have all modules included by default
* pricing is calculated by number of users
* plan restrictions by module are removed or disabled
* invoices show HT, TVA and TTC
* payment pages apply 18% TVA only at checkout
* the admin cockpit can see tenant user count, HT amount, TVA, TTC and payment status
* adding or removing users updates the subscription amount automatically

⸻

Access logic

Since all tenants now have full access:

* do not restrict modules based on subscription package
* continue to restrict user access based on roles and permissions
* tenant access should depend on payment status
* user access should depend on role, permissions and assigned features

Important distinction

Subscription controls whether the tenant is active.
Roles and permissions control what each user can access inside the tenant.

⸻

Expected result

I want a simpler subscription model:

* all tenants get full module access
* pricing is based on user count
* all prices are shown HT before payment
* 18% TVA is added at checkout
* more than 50 users triggers personalized pricing
* tenant access is granted after payment confirmation
* user access is controlled separately by roles and permissions

Please update the pricing logic, subscription UI, invoices, checkout page, admin cockpit and payment flow accordingly.
