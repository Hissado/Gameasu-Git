1. Module RH – Gestion des avances sur salaire

Le module RH doit intégrer une gestion complète des avances sur salaire.

Fonctionnalités attendues

Un employé doit pouvoir :

* demander une avance sur salaire ;
* choisir si cette avance est remboursée :
    * sur le salaire du mois en cours ;
    * sur plusieurs mois ;
    * selon un échéancier personnalisé.

Exemple :

Salaire mensuel : 100 000 FCFA

Le 10 du mois :

* avance demandée : 50 000 FCFA

Choix :

* déduction intégrale en fin de mois ;
* remboursement sur 2 mois ;
* remboursement sur 3 mois ;
* montant personnalisé chaque mois.

Le système doit automatiquement :

* calculer les retenues mensuelles ;
* alimenter la paie ;
* mettre à jour les écritures comptables ;
* afficher le solde restant dû ;
* empêcher les avances dépassant les plafonds définis par la politique RH.

Prévoir également :

* workflow d’approbation ;
* notifications ;
* historique complet ;
* pièces jointes ;
* signature électronique des validations.

⸻
