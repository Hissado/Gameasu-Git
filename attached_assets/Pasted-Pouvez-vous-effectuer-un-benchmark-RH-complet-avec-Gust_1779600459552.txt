Pouvez-vous effectuer un **benchmark RH complet avec Gusto** afin de vérifier si notre application couvre bien les fonctionnalités essentielles attendues d’une **solution RH / Paie moderne**, tout en vous assurant que le **personnel dispose également de son propre espace RH** dans l’application ?

### Objectif
Je veux évaluer si notre application dispose réellement des fonctionnalités clés qu’une bonne application RH doit proposer, en la comparant à une référence reconnue comme **Gusto**, tout en veillant à ce que le module RH ne soit pas réservé uniquement à l’administration, mais inclue aussi un véritable **espace RH collaborateur / self-service**.

### Ce que j’attends
Merci de :

- analyser les principales fonctionnalités de **Gusto**
- comparer ces fonctionnalités avec celles déjà présentes dans notre application
- identifier clairement :
  - ce que nous avons déjà
  - ce qui est partiellement couvert
  - ce qui manque
  - ce qui devrait être amélioré
- vérifier si notre application répond réellement aux standards attendus pour un module **RH / Paie** complet, professionnel et compétitif
- vous assurer que le module RH couvre à la fois :
  - les besoins de l’administration RH
  - les besoins des managers / supérieurs hiérarchiques
  - les besoins du collaborateur via un espace personnel dédié

## 2. Espace RH collaborateur / self-service
Je veux également que le **personnel ait accès à son propre espace RH** dans l’application.

### Ce que le collaborateur doit pouvoir faire
Selon ses droits, chaque employé doit pouvoir :

- consulter son profil
- mettre à jour certaines informations personnelles autorisées
- consulter ses informations administratives autorisées
- voir son contrat si applicable
- consulter ses bulletins de paie
- consulter son historique de paie si pertinent
- voir ses congés, absences, permissions et pointages
- effectuer certaines demandes RH :
  - demande de congé
  - demande d’absence
  - demande de permission
  - autres demandes internes si applicable
- consulter ses missions, formations, évaluations ou documents RH si pertinent

### Gestion des accès
Je veux bien distinguer :
- les accès de l’administration RH
- les accès du manager / supérieur hiérarchique
- les accès du collaborateur sur son propre espace

Le collaborateur doit uniquement voir :
- ses propres informations
- ses propres documents
- ses propres demandes
- ses propres données RH

L’objectif est de vérifier si notre application comporte réellement les **fonctionnalités d’une vraie application RH complète**, et d’identifier ce qu’il faut ajouter ou améliorer pour :
- atteindre un standard plus élevé
- offrir une vraie expérience RH moderne
- permettre au personnel d’interagir lui aussi avec son propre espace RH de manière simple, sécurisée et professionnelle
