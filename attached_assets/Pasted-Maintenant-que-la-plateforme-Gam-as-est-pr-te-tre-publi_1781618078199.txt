Maintenant que la plateforme Gaméasù est prête à être publiée, veuillez finaliser et sécuriser l’accès au Cockpit Plateforme afin que je puisse y accéder comme vrai utilisateur Super Admin après le déploiement.

Objectif

Je veux m’assurer qu’une fois la plateforme publiée, je pourrai me connecter au Cockpit et contrôler toute la plateforme SaaS depuis l’espace Super Admin.

Le Cockpit doit me permettre de gérer :

* les tenants / organisations
* les utilisateurs
* les abonnements
* les paiements
* les invitations
* les activations
* les suspensions
* les tickets
* les incidents
* le monitoring
* les paramètres globaux

Le lien du Cockpit est :

cockpit.gameasu.com

L’email Super Admin du Cockpit doit être :

cockpit@gameasu.com

⸻

1. Créer le vrai compte Super Admin Cockpit

Veuillez créer ou configurer un compte Super Admin réel avec l’email :

cockpit@gameasu.com

Ce compte doit avoir accès complet au Cockpit Plateforme.

Permissions Super Admin

Le compte Super Admin doit pouvoir :

* se connecter au Cockpit
* gérer tous les tenants / organisations
* créer une nouvelle organisation
* modifier une organisation
* activer ou suspendre une organisation
* générer un lien sécurisé d’onboarding pour un tenant
* inviter l’admin principal d’une organisation
* activer ou désactiver des utilisateurs
* gérer les abonnements
* gérer les paiements
* voir l’historique des paiements
* gérer les tickets support
* gérer les incidents
* voir les logs système
* voir le monitoring
* gérer les utilisateurs internes du Cockpit
* modifier les paramètres globaux de la plateforme

⸻

2. Sécuriser la première connexion

Le compte Super Admin ne doit pas utiliser un mot de passe hardcodé ou exposé.

Veuillez prévoir une logique sécurisée :

* création du compte Super Admin dans la base de données
* envoi d’un lien sécurisé de création de mot de passe
* mot de passe à définir à la première connexion
* email de vérification si nécessaire
* double authentification par email
* possibilité de changer le mot de passe depuis “Mon profil”
* option “Se souvenir de cet appareil pendant 60 jours”

⸻

3. Vérifier l’accès après publication

Veuillez tester le workflow complet après configuration :

1. Aller sur cockpit.gameasu.com
2. Se connecter avec cockpit@gameasu.com
3. Recevoir le code de vérification par email
4. Valider la connexion
5. Accéder au tableau de bord Super Admin
6. Créer un tenant / une organisation
7. Générer un lien d’onboarding
8. Inviter l’admin de l’organisation
9. Activer l’organisation
10. Activer ou désactiver des utilisateurs
11. Vérifier que les permissions Super Admin fonctionnent correctement

⸻

4. Création et gestion des tenants

Depuis le Cockpit, le Super Admin doit pouvoir ajouter une nouvelle organisation avec :

* nom de l’organisation
* email de l’administrateur principal
* nom du contact principal
* téléphone
* pays
* ville
* secteur d’activité
* nombre d’utilisateurs prévu
* statut initial
* abonnement
* frais d’installation si applicable
* lien sécurisé d’onboarding

Le Super Admin doit aussi pouvoir :

* modifier le tenant
* suspendre le tenant
* réactiver le tenant
* voir son historique
* voir ses paiements
* voir ses utilisateurs
* voir ses tickets
* voir ses incidents
* voir ses logs

⸻

5. Activation des utilisateurs

Le Super Admin doit pouvoir gérer les utilisateurs au niveau plateforme.

Il doit pouvoir :

* voir les utilisateurs par organisation
* activer un utilisateur
* désactiver un utilisateur
* réinitialiser une invitation
* renvoyer un email d’invitation
* voir le statut du compte
* voir la date de dernière connexion
* vérifier le rôle et les permissions
* forcer une réinitialisation de mot de passe si nécessaire

⸻

6. Sécurité et audit trail

Toutes les actions du Super Admin doivent être enregistrées.

Tracer notamment :

* connexion au Cockpit
* création d’un tenant
* modification d’un tenant
* activation ou suspension d’un tenant
* création d’un utilisateur
* activation ou désactivation d’un utilisateur
* génération d’un lien d’onboarding
* changement de rôle
* changement de permissions
* changement de mot de passe
* actions sur les paiements
* actions sur les tickets
* actions sur les incidents

Chaque log doit inclure :

* utilisateur
* action
* date et heure
* section concernée
* ancienne valeur
* nouvelle valeur
* adresse IP si disponible
* navigateur ou appareil si disponible

⸻

7. Résultat attendu

Je veux être certain qu’après publication :

* le Cockpit est accessible via cockpit.gameasu.com
* le compte cockpit@gameasu.com existe réellement
* ce compte est bien Super Admin
* je peux créer et gérer les tenants
* je peux activer les organisations
* je peux inviter et activer les utilisateurs
* je peux gérer les abonnements et paiements
* je peux accéder au monitoring, tickets, incidents et logs
* je peux changer mon mot de passe
* la sécurité est bien en place
* tout est prêt pour une utilisation réelle après déploiement

Objectif final

Finaliser le Cockpit Plateforme comme un vrai centre de contrôle SaaS sécurisé, afin que le Super Admin puisse contrôler toute la plateforme Gaméasù après publication.
