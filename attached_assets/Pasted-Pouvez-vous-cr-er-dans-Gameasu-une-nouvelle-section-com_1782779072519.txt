Pouvez-vous créer dans Gameasu une nouvelle section complète appelée Centre d’importation des données ou Assistant d’intégration, permettant aux clients de télécharger des templates Excel, remplir leurs données, les uploader dans l’ERP, mapper les colonnes, vérifier les erreurs et importer les informations dans les bons modules ?

Objectif

Je veux simplifier l’intégration des nouveaux clients dans Gameasu.

Le client doit pouvoir :

1. télécharger un template Excel adapté à chaque module ;
2. remplir ses données dans le fichier ;
3. uploader le fichier dans Gameasu ;
4. mapper les colonnes si nécessaire ;
5. vérifier les erreurs avant importation ;
6. corriger les données invalides ;
7. valider l’importation finale ;
8. retrouver les données importées dans les bons modules.

L’objectif est de rendre l’onboarding client plus professionnel, plus rapide et plus sécurisé.

5. Assistant d’importation en plusieurs étapes

Créer un workflow simple en 5 étapes.

Étape 1 — Choisir le module

L’utilisateur choisit le type de données à importer :

* clients
* fournisseurs
* produits
* stock
* collaborateurs
* factures
* plan comptable
* etc.

Étape 2 — Télécharger le template

L’utilisateur télécharge le template correspondant.

Afficher :

* description du template
* champs obligatoires
* ordre recommandé d’importation
* exemple de données
* bouton Télécharger le template Excel

Étape 3 — Uploader le fichier rempli

L’utilisateur téléverse son fichier rempli.

Formats acceptés :

* Excel .xlsx
* CSV .csv

Le système doit vérifier le format du fichier avant de continuer.

Étape 4 — Mapping des colonnes

Afficher un écran permettant de mapper les colonnes du fichier aux champs Gameasu.

Si le fichier utilise le template officiel, le mapping doit être automatique.

Si le fichier est personnalisé, l’utilisateur doit pouvoir mapper manuellement les colonnes.

Exemple :

* Nom client → Client Name
* Téléphone → Phone
* Email → Email
* Solde d’ouverture → Opening Balance
* Catégorie → Category

Étape 5 — Vérification et importation

Avant importation finale, Gameasu doit afficher :

* nombre total de lignes détectées
* nombre de lignes valides
* nombre de lignes avec erreurs
* nombre de doublons détectés
* champs obligatoires manquants
* formats incorrects
* aperçu des données à importer

L’utilisateur doit pouvoir cliquer sur :

Valider et importer

⸻

6. Validation automatique des données

Avant l’importation, Gameasu doit vérifier :

* champs obligatoires manquants
* doublons
* emails invalides
* numéros de téléphone invalides
* dates incorrectes
* montants mal formatés
* devises incorrectes
* TVA incorrecte
* comptes comptables inexistants
* clients inexistants
* fournisseurs inexistants
* produits inexistants
* centres analytiques inexistants
* départements inexistants
* utilisateurs inexistants
* factures déjà importées
* stock négatif
* soldes incohérents

Aucune donnée critique ne doit être importée sans validation.

⸻

7. Rapport d’erreurs téléchargeable

Si des erreurs sont détectées, Gameasu doit générer un rapport d’erreurs téléchargeable en Excel.

Ce rapport doit contenir :

* numéro de ligne
* colonne concernée
* valeur problématique
* type d’erreur
* explication claire
* correction recommandée

Exemple :

Ligne	Colonne	Erreur	Correction recommandée
12	Email	Format invalide	Entrer un email valide
18	Client	Client introuvable	Créer le client avant d’importer la facture
22	Montant TTC	Format incorrect	Utiliser uniquement des chiffres

10. Gestion des doublons

Ajouter une logique de détection des doublons.

Exemples :

* client déjà existant avec même nom ou email
* fournisseur déjà existant
* produit déjà existant
* facture déjà importée avec le même numéro
* collaborateur déjà existant avec le même email ou matricule
* compte comptable déjà existant

Le système doit proposer :

* ignorer la ligne
* mettre à jour la donnée existante
* créer une nouvelle donnée
* fusionner si applicable

11. Importation sécurisée par tenant

L’importation doit respecter l’architecture multi-tenant de Gameasu.

Chaque donnée importée doit être rattachée automatiquement à :

* organisation_id
* tenant_id
* utilisateur importateur
* module concerné

Aucune donnée d’un client ne doit être visible ou mélangée avec les données d’un autre client.
