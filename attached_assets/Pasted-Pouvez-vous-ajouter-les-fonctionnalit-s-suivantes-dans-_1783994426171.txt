Pouvez-vous ajouter les fonctionnalités suivantes dans Gameasu afin d'améliorer l'expérience utilisateur, la communication interne et la qualité du produit ?

L'objectif est de rendre l'ERP plus intuitif, plus collaboratif et plus proche des besoins réels des entreprises.

---

# 1. Ajouter un module **Réclamations** dans les Ressources Humaines

Je souhaite ajouter un nouvel onglet :

**Ressources Humaines > Réclamations**

### Objectif

Permettre aux collaborateurs de soumettre officiellement une réclamation ou une demande à leur employeur directement depuis l'ERP.

Cette fonctionnalité doit permettre d'améliorer la communication interne, d'assurer un meilleur suivi des demandes des collaborateurs et de conserver un historique des échanges.

---

## Cas d'utilisation

Un collaborateur peut par exemple réclamer :

* une erreur de paie ;
* une régularisation salariale ;
* des heures supplémentaires non prises en compte ;
* un congé non validé ;
* un remboursement de frais ;
* une erreur sur ses avantages sociaux ;
* un document RH ;
* un problème lié à son contrat ;
* une demande concernant ses droits légaux ;
* une plainte concernant ses conditions de travail ;
* toute autre réclamation interne.

---

## Fonctionnalités attendues

Le collaborateur doit pouvoir :

* créer une réclamation ;
* choisir une catégorie ;
* décrire sa demande ;
* joindre des documents ;
* suivre l'état d'avancement ;
* communiquer avec le RH si nécessaire ;
* recevoir des notifications ;
* consulter l'historique.

---

## Workflow

Statuts proposés :

* Brouillon
* Soumise
* En cours d'analyse
* Informations complémentaires demandées
* En traitement
* Résolue
* Refusée
* Clôturée

Chaque changement de statut doit être historisé.

---

## Tableau de bord RH

Le responsable RH doit pouvoir voir :

* toutes les réclamations ;
* les réclamations par collaborateur ;
* les réclamations par service ;
* les délais de traitement ;
* les réclamations urgentes ;
* les statistiques.

---

# 2. Ajouter une section **Suggestions** dans tout l'ERP

Je souhaite ajouter une fonctionnalité globale :

**Suggestions**

accessible depuis toute l'application.

### Objectif

Permettre aux utilisateurs de proposer des idées d'amélioration concernant :

* les fonctionnalités ;
* l'expérience utilisateur ;
* les processus ;
* les rapports ;
* les tableaux de bord ;
* les performances ;
* les nouveaux modules ;
* les bugs observés.

Cette fonctionnalité permettra à Gameasu de recueillir les retours des utilisateurs et d'améliorer continuellement le produit.

---

## Informations à collecter

Lorsqu'un utilisateur envoie une suggestion :

* titre ;
* catégorie ;
* description ;
* priorité proposée ;
* module concerné ;
* capture d'écran si nécessaire ;
* pièces jointes ;
* navigateur ;
* appareil utilisé ;
* organisation ;
* utilisateur.

---

## Workflow

Statuts :

* Nouvelle
* En analyse
* Acceptée
* Planifiée
* En développement
* Livrée
* Rejetée

---

## Synchronisation avec le Cockpit

Toutes les suggestions doivent être automatiquement synchronisées avec le Cockpit Gameasu.

L'équipe produit doit pouvoir :

* consulter les suggestions ;
* les classer ;
* les affecter ;
* les transformer en roadmap ;
* suivre les plus demandées.

---

# 3. Ajouter une aide contextuelle intelligente

Je souhaite améliorer considérablement l'expérience utilisateur.

Aujourd'hui, certains utilisateurs ne savent pas quoi renseigner dans certains champs.

Je souhaite donc ajouter une aide contextuelle moderne dans toute l'application.

---

## Tooltips intelligents

Lorsque l'utilisateur survole un champ avec la souris (desktop) ou clique sur une icône d'information (mobile), une aide doit apparaître automatiquement.

Exemple :

Champ :

**Date de naissance**

Le tooltip affiche :

> **Renseignez la date de naissance du collaborateur telle qu'elle figure sur sa pièce d'identité.**

---

Champ :

**Numéro fiscal**

Tooltip :

> **Saisissez le numéro fiscal officiel attribué à votre entreprise.**

---

Champ :

**Compte bancaire**

Tooltip :

> **Indiquez le compte bancaire qui sera utilisé pour les paiements.**

---

Champ :

**Mode de paiement**

Tooltip :

> **Choisissez le moyen de paiement utilisé pour cette transaction.**

---

# 4. Ajouter une description sur chaque menu

Lorsque l'utilisateur passe la souris sur un menu du sidebar ou un sous-menu, afficher une courte description.

Exemple :

### CRM

> Gérez vos prospects, clients et opportunités commerciales.

### Comptabilité

> Gérez votre comptabilité, vos écritures et vos états financiers.

### Ressources humaines

> Gérez vos collaborateurs, contrats, congés, paie et évaluations.

### Trésorerie

> Suivez vos encaissements, décaissements et soldes bancaires.

### Projets

> Planifiez, pilotez et suivez vos projets.

---

Pour les formulaires importants, afficher un petit texte sous le champ.

Exemple :

*"Nom officiel figurant sur les documents juridiques."*

---

Email

---

Téléphone

*"Inclure l'indicatif pays si nécessaire."*

---

Date d'embauche

*"Correspond à la date officielle de début du contrat."*

---

Salaire de base

---

# 6. Ajouter un mode "Première utilisation"

Lorsqu'un utilisateur ouvre un module pour la première fois, afficher une courte visite guidée.

Exemple :

Bienvenue dans le module Ressources Humaines.

Ici vous pourrez :

* créer des collaborateurs ;
* gérer les contrats ;
* suivre les congés ;
* gérer les présences ;
* lancer la paie.

Bouton :

**Commencer la visite**

ou

**Ignorer**

---

# 7. Uniformiser toute l'expérience utilisateur

Merci de parcourir l'ensemble de l'ERP afin de vérifier que chaque écran :

* possède une description claire ;
* possède une aide contextuelle lorsque nécessaire ;
* possède des messages compréhensibles ;
* possède des validations conviviales ;
* possède des messages d'erreur explicites ;
* possède des états vides utiles (Empty States) indiquant à l'utilisateur quoi faire lorsqu'aucune donnée n'existe encore.

Par exemple :

**Aucun collaborateur enregistré.**

Ajoutez votre premier collaborateur pour commencer la gestion RH.

Bouton :

**Créer un collaborateur**

---

# 8. Résultat attendu

Je souhaite que Gameasu offre une expérience utilisateur comparable aux meilleurs ERP internationaux comme **SAP, Oracle NetSuite, Microsoft Dynamics 365, Odoo, QuickBooks, Zoho One** ou **Monday.com**.

L'application doit guider l'utilisateur à chaque étape, réduire les erreurs de saisie, faciliter la prise en main et encourager les retours utilisateurs.

### Objectif final

Transformer Gameasu en un ERP **intelligent, pédagogique et centré sur l'utilisateur**, où chaque fonctionnalité est accompagnée d'une aide contextuelle, où les collaborateurs peuvent dialoguer avec leur employeur via un module de réclamations, où chaque utilisateur peut proposer des améliorations via un espace Suggestions synchronisé avec le Cockpit, et où l'expérience globale est fluide, intuitive et premium.
