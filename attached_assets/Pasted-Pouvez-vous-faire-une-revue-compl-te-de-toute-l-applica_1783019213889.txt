Pouvez-vous faire une revue complète de toute l’application **Gameasu**, y compris le **Cockpit**, afin de détecter et corriger tous les termes anglais encore visibles dans l’interface utilisateur ?

### Problème constaté

Il y a encore plusieurs termes anglais ou codes techniques visibles dans l’application alors que l’interface doit être entièrement en français.

Exemple visible dans la capture :

* `purchases.approve`
* `purchases.manage`
* `purchases.pay`
* `purchases.read`
* `purchases.write`
* `clients.manage`
* `clients.read`
* `clients.read_all`
* `admin.access`
* `audit.read`
* termes comme `bypass ACL`

Ces éléments ne doivent pas être visibles comme texte principal pour l’utilisateur final.

---

## Objectif

Je veux que toute l’interface visible par les utilisateurs soit en français, claire, professionnelle et compréhensible.

Merci de parcourir toute la codebase **ligne par ligne**, composant par composant, page par page, afin de trouver :

* termes anglais visibles ;
* labels non traduits ;
* textes techniques affichés à l’utilisateur ;
* clés de permissions visibles ;
* messages d’erreur en anglais ;
* placeholders en anglais ;
* boutons en anglais ;
* titres en anglais ;
* statuts en anglais ;
* menus en anglais ;
* textes dans le Cockpit encore en anglais ;
* anciennes variables ou données seedées affichées en anglais.

## Cas spécifique des permissions

Dans les pages **Rôles & Permissions**, les clés techniques comme :

* `purchases.read`
* `purchases.write`
* `clients.manage`
* `admin.access`

ne doivent pas être affichées directement comme texte principal.

### Comportement recommandé

Afficher plutôt des libellés français clairs :

* **Consulter les achats**
* **Créer ou modifier des achats**
* **Approuver les factures et bons de commande**
* **Enregistrer des paiements fournisseurs**
* **Gérer les clients**
* **Consulter les clients**
* **Accéder au panneau d’administration**
* **Consulter le journal d’audit**

Les clés techniques peuvent rester dans le code ou la base de données, mais elles doivent être :

* masquées pour l’utilisateur standard ;
* visibles uniquement en mode développeur si nécessaire ;
* ou affichées dans une info-bulle technique réservée aux admins avancés.

Ne pas afficher les codes techniques comme texte principal dans l’interface.

Merci de créer ou compléter un dictionnaire de traduction.

Exemples :

* `Dashboard` → Tableau de bord

* `Users` → Utilisateurs

* `Cancel` → Annuler
* `Submit` → Soumettre
