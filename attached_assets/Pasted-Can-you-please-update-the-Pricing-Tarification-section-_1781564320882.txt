Can you please update the Pricing / Tarification section of Gaméasù?

Objective

I want the pricing section to include not only the monthly subscription based on number of users, but also a clear frais d’installation / setup fee calculated per organization.

The pricing section should look professional, simple, and easy for tenants to understand.

⸻

1. Add installation fee per organization

Please add a separate pricing line called:

Frais d’installation par structure

This fee should be shown separately from the monthly subscription.

The pricing summary should clearly display:

* Nombre d’utilisateurs
* Abonnement mensuel HT
* Frais d’installation HT
* Sous-total HT
* TVA 18%
* Total TTC

Important

The setup fee must be treated as a one-time fee, not a recurring subscription fee.

It should appear during:

* tenant onboarding
* pricing page
* checkout page
* invoice
* payment summary
* cockpit billing view
* organization payment history

⸻

2. Pricing display

Before payment, all prices should be shown hors taxes / HT.

At checkout, the system should apply 18% TVA and show:

* Total HT
* TVA 18%
* Total TTC

The user must clearly understand what is recurring and what is one-time.

Example:

* Abonnement mensuel : 40 000 FCFA HT
* Frais d’installation : 100 000 FCFA HT
* TVA 18%
* Total à payer aujourd’hui : montant TTC

⸻

3. Add custom application option

Please add a special section in the pricing page for organizations that want a personalized application.

Text suggestion:

Vous souhaitez une application personnalisée pour votre organisation ?
Contactez-nous. L’équipe Gaméasù vous accompagne pour concevoir une solution adaptée à vos besoins, à vos processus et à votre secteur d’activité.

Add a button:

Contacter Gaméasù

or

Demander une application personnalisée

⸻

4. Custom application workflow

When the user clicks the button, the system should allow them to submit a request with:

* organization name
* contact person
* email
* phone number
* country
* industry
* description of needs
* number of expected users
* preferred timeline
* budget range if applicable

This request should be sent to the Cockpit Platform so the Gaméasù team can follow up properly.

⸻

5. Cockpit integration

In the Cockpit Platform, please add a section for:

Demandes d’applications personnalisées

Gaméasù admins should be able to:

* view custom app requests
* filter by status
* assign the request to a team member
* add internal notes
* update status
* contact the organization
* convert the request into a quote or project

Statuses:

* Nouvelle demande
* En analyse
* En discussion
* Devis envoyé
* Acceptée
* Refusée
* Clôturée

⸻

6. Final objective

The Pricing section should clearly show:

* user-based subscription pricing
* one-time installation fee per organization
* HT pricing before checkout
* TVA 18% at payment
* custom application request option
* clean integration with billing, invoices, payments and Cockpit Platform

The goal is to make the pricing page more complete, professional and ready for real SaaS sales.
