Pouvez-vous revoir la logique du bouton d’inscription sur la page de connexion de l’ERP Gameasu ?

Problème constaté

Actuellement, la page login affiche :

Vous n’avez pas encore de compte ?
Demander un accès Gameasu

Cette formulation n’est pas totalement cohérente avec le parcours SaaS souhaité.

Je ne veux pas que le client ait l’impression qu’il doit simplement demander un accès et attendre une validation manuelle. La logique doit plutôt être celle d’une inscription directe, suivie du choix de la formule, du paiement, puis de l’activation de l’espace ERP.

⸻

Logique attendue

Sur la page login, remplacer :

Demander un accès Gameasu

par :

Créer un compte

ou

Créer mon compte Gameasu

Affichage recommandé

Vous n’avez pas encore de compte ?
Bouton : Créer un compte

⸻

Parcours attendu après clic

Quand le client clique sur Créer un compte, il doit être redirigé vers le parcours normal d’inscription et d’abonnement.

Étapes attendues

1. Le client clique sur Créer un compte depuis la page login.
2. Il arrive sur une page de sélection de formule.
3. Il choisit son pack :
    * Starter
    * Business
    * Premium
    * Offre personnalisée
4. Il choisit le nombre d’utilisateurs.
5. Il choisit la périodicité :
    * mensuelle
    * trimestrielle
    * semestrielle
    * annuelle
6. Le système calcule automatiquement le montant.
7. Le client renseigne ses informations :
    * nom complet ;
    * email ;
    * téléphone ;
    * nom de l’entreprise ;
    * secteur d’activité ;
    * pays ;
    * ville ;
    * mot de passe.
8. Le système crée son organisation dans l’ERP.
9. L’utilisateur devient automatiquement Super Administrateur de cette organisation.
10. Le client continue vers le paiement.
11. Après paiement confirmé, l’accès à l’ERP est activé selon le pack choisi.

⸻

Cas spécifique

Si le client vient directement de la page Tarifs du site web avec une formule déjà choisie, il ne doit pas refaire toute la sélection.

Exemple :

/erp/billing?plan=business&users=10&period=monthly

Dans ce cas, la page doit préremplir automatiquement :

* formule : Business ;
* nombre d’utilisateurs : 10 ;
* périodicité : mensuelle ;
* montant calculé.

Mais si le client clique simplement sur Créer un compte depuis la page login, il doit d’abord passer par le sélecteur de formule.

⸻

Texte à éviter

Éviter :

* Demander un accès Gameasu
* Soumettre une demande
* Notre équipe vous contactera
* Accès en attente de validation

Ces textes donnent l’impression que l’inscription n’est pas automatique.

⸻

Texte recommandé

Utiliser plutôt :

* Créer un compte
* Créer mon compte Gameasu
* Commencer avec Gameasu
* Choisir ma formule
* Continuer vers le paiement
* Activer mon espace ERP

⸻

Résultat attendu

Je veux que la page login suive une logique SaaS plus claire :

* les clients existants se connectent ;
* les nouveaux clients cliquent sur Créer un compte ;
* ils choisissent leur formule, le nombre d’utilisateurs et la périodicité ;
* ils créent leur organisation ;
* ils paient ;
* ils accèdent à l’ERP selon leur pack.

Objectif final

Rendre le parcours d’inscription Gameasu plus naturel, plus professionnel et plus cohérent : le bouton de la page login doit lancer un vrai parcours de création de compte, d’abonnement et de paiement, au lieu de donner l’impression d’une simple demande d’accès manuelle.
