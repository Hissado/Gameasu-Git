Refonte de l’architecture du module Équipe & Ressources Humaines

Je propose de revoir complètement la structure du module Équipe & RH afin qu’il soit plus intuitif, évolutif et conforme aux standards des ERP de niveau Enterprise.

Objectif

Je souhaite que la navigation RH soit organisée selon une hiérarchie logique à trois niveaux, permettant à l’utilisateur de comprendre immédiatement où il se trouve et de retrouver facilement les fonctionnalités recherchées.

Cette architecture doit également permettre d’ajouter de nouvelles fonctionnalités dans le futur sans désorganiser le menu.

⸻

Structure de navigation souhaitée

Niveau 1 : Les grandes catégories (barre bleue)

Les éléments affichés en gras dans la barre latérale représentent les grands domaines fonctionnels des Ressources Humaines.

Exemples :

* Mon espace
* Collaborateurs
* Recrutement
* Intégration
* Structure
* Temps & Présence
* Paie
* Formalités administratives
* Documents du personnel
* Documents légaux
* Notation & Rapports
* Paramètres
* Archivage
* Réclamations & Suggestions
* Journal d’audit

Ces catégories constituent les points d’entrée principaux du module RH.

⸻

Niveau 2 : Les rubriques détaillées

Lorsqu’un utilisateur clique sur une grande catégorie, celle-ci se déploie pour afficher les fonctionnalités principales.

Par exemple :

* Dossiers de candidature
* Lettres d’embauche
* Visites médicales

Intégration

* Informations du collaborateur

Structure

* Départs
* Retraite

Respecter cette hiérarchie dans toute l’application

Toute la navigation RH doit suivre cette logique :

Grande catégorie → Rubrique → Sous-rubrique

L’utilisateur ne doit jamais voir une longue liste de fonctionnalités au même niveau.

⸻

Une architecture pensée pour évoluer

Cette nouvelle structure servira de base.

Dans un premier temps, l’objectif est de mettre en place une architecture propre et cohérente.

Ensuite, nous enrichirons progressivement chaque rubrique avec :

* les fonctionnalités métier ;
* les écrans ;
* les workflows ;
* les validations ;
* les rapports ;
* les tableaux de bord ;
* les automatisations ;
* les IA ;
* les intégrations externes.

Ainsi, Gameasu pourra évoluer naturellement sans qu’il soit nécessaire de réorganiser le menu à chaque nouvelle fonctionnalité.

⸻

Uniformiser cette logique dans tous les modules

Cette approche ne doit pas être limitée au module RH.

Les modules :

* Ventes
* Achats
* Finance
* Comptabilité
* Logistique
* Projets
* Marketing
* CRM
* Administration

doivent adopter la même logique de navigation hiérarchique.

L’expérience utilisateur sera ainsi cohérente dans tout l’ERP.

⸻

Expérience utilisateur

Je souhaite que la navigation donne immédiatement une vision globale des possibilités offertes par Gameasu.

Un nouvel utilisateur doit comprendre instinctivement :

* où il se trouve ;
* ce que contient chaque grande catégorie ;
* quelles sont les étapes logiques d’un processus RH ;
* où retrouver une fonctionnalité.

L’objectif est de réduire au maximum le temps d’apprentissage de l’ERP.

⸻

Résultat attendu

Je souhaite transformer le module Équipe & RH en un module parfaitement organisé, intuitif et évolutif, avec une navigation à trois niveaux (Catégorie → Rubrique → Sous-rubrique), inspirée des meilleurs ERP du marché (SAP SuccessFactors, Oracle HCM, Microsoft Dynamics 365 Human Resources, Workday et Odoo Enterprise).

Cette architecture servira de fondation pour enrichir progressivement toutes les fonctionnalités RH, tout en conservant une navigation simple, cohérente et agréable pour les utilisateurs.
