Can you please create a separate secure Cockpit Platform for Gaméasù?

Objective

I do not want the Cockpit Platform to be inside the main tenant app.
It should be a separate, secure platform accessible only by authorized Gaméasù administrators.

This platform will be used to manage:

* tenants / organizations
* subscription payments
* user access
* support tickets
* technical issues
* app monitoring
* bugs
* downtime
* system health
* platform operations

⸻

1. Separate secure platform

Please create a separate secure platform, for example:

* cockpit.gameasu.com
* admin.gameasu.com
* or another secure admin URL

This should not appear in the normal tenant application sidebar.

Only authorized Gaméasù internal admins should be able to access it.

⸻

2. Authentication and security

The Cockpit Platform must have strong security:

* secure login
* role-based access
* super admin access
* internal admin access
* two-factor authentication if possible
* protected routes
* backend permission checks
* audit trail
* login history
* IP/device tracking if possible

No tenant user should be able to access this platform.

⸻

3. Tenant and subscription management

The Cockpit Platform should allow Gaméasù admins to manage:

* all tenants / organizations
* subscription status
* payment status
* invoices
* receipts
* user count
* active / suspended / expired tenants
* renewal dates
* failed payments
* manual activation or suspension
* payment history
* plan pricing and billing rules

When a tenant pays successfully, the Cockpit should show the payment confirmation and the tenant access should be updated automatically.

⸻

4. Support tickets and user issues

Please add a full support ticket system inside the Cockpit Platform.

Gaméasù admins should be able to:

* view all tickets
* filter by tenant
* filter by priority
* filter by status
* assign tickets to internal team members
* respond to tickets
* update ticket status
* attach screenshots or files
* track ticket history
* close or reopen tickets

Ticket statuses should include:

* New
* Open
* In progress
* Waiting for customer
* Resolved
* Closed

Priority levels:

* Low
* Medium
* High
* Critical

⸻

5. App monitoring and technical diagnostics

The Cockpit Platform should help assess technical issues in the app.

If the app has a bug, downtime, slow performance, or technical issue, the Cockpit should help identify where the problem is.

Please include monitoring for:

* app uptime
* API health
* database health
* authentication issues
* payment gateway issues
* failed webhooks
* frontend errors
* backend errors
* slow endpoints
* failed jobs
* failed emails
* failed SMS / WhatsApp messages
* tenant-specific errors

⸻

6. Incident and downtime management

Please add an incident management section.

Admins should be able to:

* create an incident
* track active incidents
* identify affected tenants
* define severity level
* document the issue
* assign an owner
* track resolution steps
* mark incident as resolved
* keep incident history

Severity levels:

* Minor
* Major
* Critical
* Platform down

⸻

7. Logs and audit trail

The Cockpit Platform should include logs for:

* tenant activity
* user logins
* subscription changes
* payment events
* webhook events
* failed payments
* API errors
* admin actions
* permission changes
* system events

Every important action must be recorded with:

* user
* date and time
* action performed
* tenant affected
* old value
* new value
* IP/device if available

⸻

8. Platform dashboard

Create a dashboard with key metrics:

* total tenants
* active tenants
* suspended tenants
* monthly recurring revenue
* pending payments
* failed payments
* open tickets
* critical tickets
* active incidents
* uptime status
* API health
* database health
* recent errors

⸻

9. Separation from tenant app

Important:

The Cockpit Platform must be separate from the tenant application.

The tenant app is for organizations using Gaméasù.
The Cockpit Platform is for Gaméasù internal administration.

Do not show the Cockpit Platform menu inside the tenant app.

⸻

10. Final objective

Create a secure, separate, professional Cockpit Platform where Gaméasù can manage tenants, payments, subscriptions, support tickets, bugs, incidents, downtime, system health, logs, and platform operations from one centralized internal control center.
