Je souhaite que vous réalisiez une refonte complète de l’expérience utilisateur (UX) et de l’interface (UI) de Gameasu afin d’obtenir un ERP beaucoup plus intuitif, moderne et accessible aussi bien aux utilisateurs débutants qu’aux utilisateurs expérimentés.

L’objectif est de réduire la courbe d’apprentissage et d’offrir une expérience premium comparable à QuickBooks, Xero, Microsoft Dynamics 365, Notion ou Monday.com.

⸻

1. Revoir l’affichage du pack d’abonnement

Aujourd’hui, le Dashboard affiche « Professionnel ».

Je souhaite remplacer cette information par le nom réel du pack souscrit.

Par exemple :

* Starter
* Business
* Premium
* Enterprise

Le badge devra être plus moderne et afficher également :

* le nombre d’utilisateurs inclus ;
* le nombre d’utilisateurs utilisés ;
* la périodicité (mensuel ou annuel) ;
* la date de renouvellement ;
* la date d’expiration de l’abonnement ;
* le nombre de jours restants avant expiration.

L’objectif est que le client sache immédiatement où il en est dans son abonnement et ne puisse pas dire qu’il a oublié de le renouveler.

⸻

2. Ajouter des raccourcis intelligents

Créer une section “Raccourcis” facilement accessible depuis le Dashboard.

Je souhaite notamment y retrouver :

* Visite guidée
* Faire une suggestion
* Mon espace
* Centre d’aide
* Documentation
* Contacter le support
* Nouveautés
* Historique des mises à jour

Ces raccourcis devront être visibles mais discrets afin de faciliter l’accès aux fonctions importantes.

⸻

3. Supprimer les informations inutiles

Supprimer les éléments qui n’apportent pas de valeur à l’utilisateur.

Par exemple :

* Gameasu V.2026

À la place, prévoir éventuellement un lien discret vers :

À propos de Gameasu

ou

Notes de version

accessible uniquement si l’utilisateur le souhaite.

⸻

4. Ajouter une description simple sous chaque module

Gameasu est un ERP très riche.

Pour les utilisateurs ayant peu d’expérience, chaque module doit comporter une courte phrase expliquant son rôle.

Exemples :

Ressources Humaines

“Gérez votre personnel, les contrats, les congés, les absences et la paie.”

Comptabilité

“Gérez votre argent, vos opérations comptables et vos obligations fiscales.”

CRM

“Gérez vos clients, prospects et opportunités commerciales.”

Ventes

“Créez vos devis, factures et suivez vos paiements.”

Achats

“Gérez vos fournisseurs, commandes et dépenses.”

Projets

“Planifiez et suivez vos projets de A à Z.”

Stocks

“Gérez vos produits et vos mouvements de stock.”

Documents

“Centralisez tous vos fichiers en toute sécurité.”

Tableaux de bord

“Visualisez vos indicateurs clés en temps réel.”

Ces descriptions doivent être visibles :

* dans le menu principal ;
* sur les cartes des modules ;
* dans les pages d’accueil de chaque module.

⸻

5. Ajouter une description sur chaque sous-module

Le même principe doit s’appliquer aux sous-sections.

Exemple :

Employés

“Gérez les informations et le dossier de chaque collaborateur.”

Congés

“Gérez les demandes de congés et leur validation.”

Présences

“Suivez les heures de travail et les pointages.”

Factures

“Créez et envoyez des factures conformes.”

Paiements

“Suivez les règlements reçus et les soldes clients.”

Journal Comptable

“Consultez toutes les écritures comptables.”

L’objectif est que l’utilisateur comprenne immédiatement ce qu’il peut faire dans chaque écran.

⸻

6. Revoir complètement la visite guidée

Le système de visite guidée doit être entièrement repensé.

Aujourd’hui, les fenêtres sont trop grandes et masquent les boutons de navigation. Issa notes.docx

Je souhaite :

* des pop-ups plus petits ;
* une meilleure disposition à l’écran ;
* un positionnement intelligent selon l’élément expliqué ;
* un bouton “Suivant” toujours visible ;
* un bouton “Précédent” ;
* un bouton “Ignorer” ;
* une barre de progression ;
* la possibilité de reprendre la visite plus tard.

Prévoir plusieurs parcours :

* Première connexion
* Comptabilité
* RH
* CRM
* Facturation
* Assistant IA
* Cockpit
* Portail Expert

⸻

7. Assistant d’apprentissage

Créer un véritable mode d’apprentissage.

Lorsqu’un utilisateur ouvre un module pour la première fois, Gameasu doit lui expliquer :

* ce qu’est le module ;
* à quoi il sert ;
* quelles sont les principales actions possibles ;
* quelles sont les meilleures pratiques.

L’utilisateur pourra ensuite désactiver définitivement cette aide.

⸻

8. Infobulles intelligentes

Sur chaque champ important, ajouter une infobulle expliquant précisément ce qui est attendu.

Exemple :

Date de naissance

“Indiquez la date de naissance figurant sur la pièce d’identité.”

Numéro fiscal

“Saisissez le numéro d’identification fiscale de l’entreprise.”

Compte comptable

“Sélectionnez le compte qui sera utilisé lors de la génération automatique des écritures.”

Ces aides doivent améliorer l’expérience utilisateur sans encombrer l’interface.

⸻

9. Interface plus humaine

Je souhaite rendre l’ERP plus accueillant.

Par exemple :

Au lieu d’afficher uniquement le nom du module, afficher des messages comme :

* Bonjour Issa 👋
* Bon retour !
* Que souhaitez-vous faire aujourd’hui ?
* Vous avez 3 factures en attente.
* 2 déclarations fiscales arrivent à échéance.
* Félicitations, toutes vos sauvegardes sont à jour.

⸻

10. Personnalisation du Dashboard

Permettre à chaque utilisateur de choisir les widgets affichés :

* trésorerie ;
* ventes ;
* factures ;
* projets ;
* RH ;
* calendrier ;
* Assistant IA ;
* notifications ;
* tâches ;
* objectifs.

Le Dashboard doit devenir entièrement personnalisable.

⸻

11. Vérification générale

Enfin, réalisez un audit complet de l’expérience utilisateur afin d’identifier :

* les écrans trop chargés ;
* les informations inutiles ;
* les actions qui nécessitent trop de clics ;
* les incohérences de navigation ;
* les améliorations possibles pour rendre Gameasu plus fluide, intuitif et professionnel.

L’objectif est que chaque utilisateur, même sans expérience en ERP, puisse comprendre rapidement le fonctionnement de Gameasu grâce à une interface claire, pédagogique et agréable, tout en conservant la puissance fonctionnelle attendue d’un ERP de niveau Enterprise.
