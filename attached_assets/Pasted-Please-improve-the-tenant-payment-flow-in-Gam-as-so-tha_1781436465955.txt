Please improve the tenant payment flow in Gaméasù so that organizations can pay their subscription by card, with an option to enable autopay, and receive automatic access once the payment is confirmed.

Objective

When a tenant chooses to pay by card, the system must provide a secure card payment experience and automatically activate or renew the tenant’s access after successful payment.

Card payment form

Please add a secure card payment form with the required fields:

* card number
* expiration date
* CVV
* cardholder name
* billing address if required
* email for receipt
* payment amount
* selected subscription plan
* billing frequency: monthly or annual

Important security requirement

Do not store raw card numbers, CVV, or sensitive card data directly in our database.

Use a secure payment gateway integration such as:

* Stripe
* PayDunya
* CinetPay
* Flutterwave
* or another PCI-compliant provider

The card data should be handled through secure hosted fields, tokenization, or the provider’s checkout system.

Autopay option

Please add an Autopay / Automatic Renewal option.

The tenant should be able to:

* enable autopay during checkout
* save a payment method securely through the payment provider
* automatically renew monthly or annually
* disable autopay later from Abonnement & Facturation
* update the saved payment method
* receive notifications before renewal
* receive confirmation after successful renewal
* receive an alert if autopay fails

Payment confirmation

Once the payment is completed, the system must automatically:

* verify the payment status from the payment provider
* update the transaction status to Confirmed
* generate a receipt
* generate or mark the SaaS invoice as paid
* activate or renew the tenant subscription
* update the subscription start and end dates
* grant access to the tenant
* activate the correct plan and modules
* update user limits based on the selected package
* notify the tenant by email and in-app notification

Webhook logic

Please implement webhook handling so that payment confirmation is automatic.

The webhook must:

* receive payment confirmation from the provider
* verify the webhook signature
* match the transaction to the correct tenant
* prevent duplicate processing
* update the payment status
* activate access only after confirmed payment
* log the full transaction history

Payment statuses

Please support these statuses:

* Pending
* Confirmed
* Failed
* Cancelled
* Expired
* Refunded

Abonnement & Facturation page

Update the tenant billing page to show:

* current plan
* subscription status
* next renewal date
* autopay status
* saved payment method summary, for example last 4 digits only
* invoices
* receipts
* payment history
* button: Pay now
* button: Enable autopay
* button: Disable autopay
* button: Update payment method

Access logic

If payment is confirmed:

* tenant status becomes Active
* access is granted immediately
* subscribed modules are unlocked
* plan limits are applied

If payment fails:

* tenant remains unpaid or past due
* access is not granted or renewal is not completed
* user receives a clear message
* admin receives a notification if necessary

Final objective

Create a secure and professional tenant payment system where organizations can pay by card, enable autopay, receive automatic payment confirmation, and get immediate access to Gaméasù once payment is successfully confirmed.
