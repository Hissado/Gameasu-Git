Pouvez-vous améliorer le **Cockpit Plateforme Gaméasù** afin qu’il devienne une vraie plateforme interne de gestion, d’administration, de monitoring et de support SaaS ?

### Objectif

Je veux que le Cockpit ne soit pas seulement un tableau de bord, mais un vrai centre de contrôle interne permettant à l’équipe Gaméasù de gérer :

* les tenants / organisations
* les utilisateurs du cockpit
* les accès internes
* les abonnements
* les paiements
* les tickets support
* les incidents techniques
* la santé de la plateforme
* les logs
* le monitoring
* les paramètres du système

Le Cockpit doit être accessible uniquement via :

**cockpit.gameasu.tech**

---

## 1. Ajouter la création de tenants depuis le Cockpit

Veuillez permettre au Super Admin de créer directement un nouveau tenant / une nouvelle organisation depuis le Cockpit.

### Fonctionnalités attendues

Le Super Admin doit pouvoir :

* ajouter une nouvelle organisation
* saisir le nom de l’organisation
* ajouter le contact principal
* ajouter l’email de l’administrateur organisation
* définir le pays, ville, secteur d’activité
* définir le nombre d’utilisateurs estimé
* définir le statut : actif, en attente, suspendu, expiré
* générer un lien sécurisé d’onboarding
* envoyer le lien par email
* suivre le statut d’activation
* modifier ou suspendre l’organisation
* consulter l’historique du tenant

Chaque tenant créé doit être automatiquement isolé avec son propre `organization_id`.

## 2. Gestion des utilisateurs du Cockpit

Je veux pouvoir donner accès au Cockpit à certains utilisateurs internes de Gaméasù.

### Fonctionnalités attendues

Le Super Admin doit pouvoir :

* ajouter un utilisateur Cockpit
* inviter un utilisateur par email
* définir son rôle
* définir ses permissions
* activer ou désactiver son accès
* réinitialiser son mot de passe si nécessaire
* voir la date de dernière connexion
* consulter ses actions dans l’audit trail

### Exemples de rôles Cockpit

* Super Admin
* Admin Plateforme
* Responsable Support
* Responsable Finance
* Responsable Technique
* Responsable Commercial
* Lecture seule

### Permissions possibles

* gérer les tenants
* gérer les paiements
* gérer les abonnements
* gérer les tickets
* gérer les incidents
* voir les logs techniques
* voir les rapports SaaS
* accéder au monitoring
* gérer les utilisateurs Cockpit
* modifier les paramètres plateforme

## 3. Gestion du profil et du mot de passe

Veuillez ajouter une section **Mon profil** dans le Cockpit.

L’utilisateur du Cockpit doit pouvoir :

* voir son nom
* voir son email
* changer son mot de passe
* activer ou désactiver la double authentification si applicable
* voir ses appareils connectés
* voir ses dernières connexions
* se déconnecter de tous les appareils
* mettre à jour ses informations de profil

### Sécurité

Le changement de mot de passe doit demander :

* mot de passe actuel
* nouveau mot de passe
* confirmation du nouveau mot de passe
* validation des règles de sécurité
* confirmation par email si nécessaire

## 7. Sécurité et audit trail

Toutes les actions sensibles doivent être enregistrées.

Tracer notamment :

* création d’un tenant
* modification d’un tenant
* suspension ou réactivation
* création d’un utilisateur Cockpit
* changement de rôle
* changement de permissions
* changement de mot de passe
* connexion réussie
* tentative de connexion échouée
* paiement modifié
* ticket modifié
* incident créé ou résolu

Chaque log doit contenir :

* utilisateur
* action
* date et heure
* section concernée
* ancienne valeur
* nouvelle valeur
* adresse IP si disponible
* appareil ou navigateur si disponible
